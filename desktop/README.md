# نسخه ویندوز — رزومه‌یار

این پوشه همان برنامه را داخل یک پنجره بومی ویندوز اجرا می‌کند؛ بدون تب مرورگر. خروجی، یک فایل اجرایی و در صورت نصب بودن Inno Setup، یک فایل نصب است.

فایل‌های بیلد داخل مخزن نگه داشته نمی‌شوند؛ با `build_windows.bat` ساخته می‌شوند. خروجی برای **Windows 10/11 (64-bit)** است. نصب به‌صورت per-user انجام می‌شود و به دسترسی Administrator نیاز ندارد.

## نصب

فایل نصبی در مخزن نگه داشته نمی‌شود؛ اول با `build_windows.bat` بسازید، بعد:

1. فایل `installer\Resumeyar-Setup-1.0.0.exe` را اجرا کنید.
2. اگر Windows SmartScreen هشدار داد، **More info** و سپس **Run anyway** را بزنید (فایل امضای تجاری ندارد).
3. مسیر پیش‌فرض نصب: `%LOCALAPPDATA%\Programs\Resumeyar`
4. در پایان می‌توانید گزینه اجرای برنامه را بزنید. میانبر در Start Menu ساخته می‌شود؛ میانبر دسکتاپ اختیاری است.

حذف برنامه از **Settings → Apps → رزومه‌یار → Uninstall** انجام می‌شود.

## اجرا

برنامه یک پنجره بومی ویندوز است و مرورگر خارجی باز نمی‌کند. موتور نمایش از WebView2 خود ویندوز استفاده می‌کند؛ سرور محلی فقط داخل همین فرایند روی `127.0.0.1` (از پورت 5533 به بالا) بالا می‌آید و از بیرون قابل دسترسی نیست.

1. `Resumeyar.exe` را اجرا کنید. پنجره برنامه باز می‌شود و مستقیم وارد داشبورد می‌شوید.
2. اگر WebView2 Runtime روی سیستم نباشد، ویندوز 10/11 معمولاً آن را دارد؛ در غیر این صورت پیام خطای قابل خواندن نشان داده می‌شود.
3. برای پایان کار پنجره را ببندید. سرور محلی هم همان لحظه خاموش می‌شود.
4. برای تست بدون بیلد، `run_desktop.bat` را اجرا کنید (از محیط `..\.venv` استفاده می‌کند).

### پیش‌نمایش و دانلود

- در صفحه ساخت رزومه، تیک **نمایش فایل بعد از ساخت** را بزنید تا PDF بلافاصله بالای همان صفحه نمایش داده شود.
- در همان نوار پیش‌نمایش، دکمه **دانلود رزومه** فایل را با پنجره ذخیره بومی ویندوز ذخیره می‌کند و دکمه **رفتن به ارسال** مستقیم به بخش ارسال ایمیل می‌رود.
- PDF هر زمان از صفحه درخواست هم قابل دانلود است؛ دانلود در پوشه‌ای که خودتان در پنجره Save انتخاب می‌کنید ذخیره می‌شود.

## محل داده‌ها

همه اطلاعات در این پوشه ذخیره می‌شود:

```
%LOCALAPPDATA%\Resumeyar
├── resumeyar.db      # پروفایل، آگهی‌ها، درخواست‌ها، تنظیمات
├── uploads\          # CV و مدارک بارگذاری‌شده
├── generated\        # PDFهای رزومه، کاور لتر و بسته ارسال
├── secret.key        # کلید نشست برنامه
├── webview\          # حافظه مرورگر داخلی (کوکی نشست و کش)
└── launcher.log      # لاگ اجرا (برای عیب‌یابی)
```

با حذف برنامه این داده‌ها پاک **نمی‌شوند**؛ قبل از حذف برنامه، اگر لازم است از دکمه پشتیبان‌گیری در تنظیمات استفاده کنید یا پوشه را دستی نگه دارید.

## نسخه پرتابل

پوشه کامل `dist\Resumeyar` پرتابل است: می‌توانید آن را روی فلش یا هر مسیری کپی کنید و `Resumeyar.exe` را اجرا کنید. داده‌ها همچنان در `%LOCALAPPDATA%\Resumeyar` ذخیره می‌شوند.

## چه چیزهایی کار می‌کند؟

- خواندن CV (PDF، DOCX، TXT) و بارگذاری مدارک
- جست‌وجو و ایمپورت آگهی، تشخیص نوع همکاری (حضوری/ترکیبی/دورکاری) و نوع قرارداد
- بهینه‌سازی CV و ساخت کاور لتر (با AI در صورت تنظیم کلید، یا روش قاعده‌محور)
- تولید PDF رزومه و کاور لتر، بایگانی درخواست‌ها، پشتیبان ZIP و ارسال ایمیل SMTP با تأیید انسانی
- نمایش PDF داخل برنامه و ذخیره آن با پنجره بومی ویندوز در مسیر دلخواه

## حریم خصوصی و شبکه

سرور فقط روی `127.0.0.1` گوش می‌دهد و از بیرون قابل دسترسی نیست. ارتباط‌های خروجی فقط در سه حالت:

- دریافت آگهی از سایت‌های شغلی
- سرویس هوش مصنوعی، اگر خودتان کلید و آدرس را در تنظیمات وارد کنید
- سرور SMTP، اگر ایمیل تنظیم کنید

## نکته‌های فنی

- **هوش مصنوعی:** کتابخانه `openai` داخل بسته نیست تا حجم کم بماند. تنظیمات AI با API سازگار OpenAI از طریق HTTP کار می‌کند؛ فقط کلید/آدرس/مدل را در تنظیمات وارد کنید.
- **پنجره برنامه:** با `pywebview` روی WebView2 اجرا می‌شود (`requirements_desktop.txt`). دانلودها با تنظیم `ALLOW_DOWNLOADS` به پنجره Save بومی ویندوز وصل می‌شوند؛ بدون این تنظیم، کلیک دانلود بی‌صدا رد می‌شود.
- **تولید PDF:** فونت وزیرمتن و فایل‌های ReportLab داخل بسته هستند؛ نیازی به نصب چیز دیگری نیست.
- **نصب‌کننده:** با Inno Setup 6 ساخته می‌شود، per-user، بدون UAC. امضای دیجیتال تجاری ندارد.
- **دفاع Windows Defender:** ممکن است فایل بدون امضا را به‌عنوان ناشر ناشناخته علامت بزند؛ ساخت داخل سازمان/شخصی است و کد آن در همین پوشه قابل بررسی است.

## ساخت مجدد

روی ویندوز:

```bat
cd desktop
build_windows.bat
```

اسکریپت اول `pywebview` را از فایل `requirements_desktop.txt` نصب می‌کند، بعد با PyInstaller از محیط `..\.venv` بیلد می‌سازد و اگر Inno Setup 6 نصب باشد، نصب‌کننده را هم می‌سازد.

اگر شبکه اجازه دسترسی به pypi.org را نمی‌دهد، پیش از اجرای اسکریپت متغیر `PIP_INDEX_URL` را روی آینه pip خودتان تنظیم کنید؛ pip به‌صورت خودکار از آن استفاده می‌کند.

خروجی‌ها:

```
dist\Resumeyar\Resumeyar.exe
installer\Resumeyar-Setup-1.0.0.exe
```

## ساختار پوشه

```
desktop/
  launcher.py          # پنجره بومی pywebview + اجرای سرور Flask
  run_desktop.bat      # اجرای بدون بیلد از venv
  requirements_desktop.txt  # pywebview
  resumeyar.spec       # تنظیمات PyInstaller
  version_info.txt     # مشخصات فایل EXE
  installer.iss        # اسکریپت Inno Setup
  build_windows.bat    # ساخت EXE و نصب‌کننده
  assets/              # آیکون
  dist/                # خروجی پرتابل
  installer/           # فایل Setup
```

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| پنجره سفید یا خالی باز می‌شود | WebView2 Runtime را از سایت مایکروسافت نصب کنید؛ نسخه دیگری از برنامه باز نباشد؛ نسخه جدید خودش پیام خطا نشان می‌دهد |
| «رزومه یار از قبل باز است» | یک پنجره از برنامه باز است؛ همان را ببندید یا از آن استفاده کنید |
| «راه‌اندازی سرور ناموفق بود» | `%LOCALAPPDATA%\Resumeyar\launcher.log` را ببینید؛ احتمالاً پورت‌ها اشغال یا فایل آنتی‌ویروس حذف شده است |
| «نمایشگر برنامه بالا نیامد» | پنجره در ۴۵ ثانیه لود نشده؛ برنامه را دوباره اجرا کنید و اگر تکرار شد WebView2 Runtime را نصب کنید |
| دانلود شروع نمی‌شود | مطمئن شوید نسخه جدید را اجرا می‌کنید؛ نسخه‌های قدیمی‌تر دانلود در پنجره داخلی را مسدود می‌کردند |
| SmartScreen | More info → Run anyway |
| داده‌های قبلی لازم است | پوشه `%LOCALAPPDATA%\Resumeyar` را نگه دارید یا از پشتیبان ZIP استفاده کنید |
